# GigaVibeMiptCode

Консольный ИИ-ассистент. Принимает сообщения с клавиатуры, отправляет
их в LLM через OpenAI-совместимое API и печатает ответ.

## Возможности

- Чат с LLM с историей сообщений.
- Ограничение контекста: по числу сообщений (`limit_message`) и по числу
  символов (`limit_chars`). Самые старые сообщения удаляются, а если
  одно сообщение длиннее `limit_chars` — оно обрезается слева.
- Настройка через переменные окружения **или** `config.yaml`
  (переменные окружения имеют приоритет).
- Прерывание ожидания ответа модели по `Ctrl+C` (возвращает к вводу).
- Подстановка содержимого файлов через `@::путь::` (макс. 5 МБ на файл).
- Режим обработки файла по чанкам: `/file_chunk` (по абзацам, по
  нескольким абзацам или по числу символов), флаг `-y` для авторежима.
- Команда `/reset` — сброс истории и очистка экрана.
- Команда `\q` — выход.
- Streaming-вывод ответа модели (по мере генерации).

## Установка

Требуется Python 3.10+.

```bash
pip install -r requirements.txt
```

В качестве LLM можно использовать [Ollama](https://ollama.com/) или любой
другой OpenAI-совместимый провайдер. Пример с Ollama:

```bash
ollama pull gemma3:270m
```

## Настройка

### Через переменные окружения (UNIX)

```bash
export API_KEY=ollama
export API_HOST=http://localhost:11434/v1/
export MODEL=gemma3:270m
export LIMIT_MESSAGE=20
export LIMIT_CHARS=4000
export TEMPERATURE=0.3
python main.py
```

### Через `config.yaml`

Скопируйте пример и заполните:

```bash
cp config.example.yaml config.yaml
```

Содержимое:

```yaml
api_key: ollama
api_host: http://localhost:11434/v1/
model: gemma3:270m
limit_message: 20
limit_chars: 4000
temperature: 0.3
system_prompt: You are a helpful AI assistant.
```

Файл уже добавлен в `.gitignore`, в него можно безопасно класть секреты.

Переменные окружения, если заданы, перекрывают значения из `config.yaml`.
Если нет ни того, ни другого — программа сообщит об этом и завершится.

## Команды

| Команда | Описание |
| --- | --- |
| `\q` | Выйти из программы (или из режима `/file_chunk`). |
| `/reset` | Очистить историю сообщений и экран. |
| `/file_chunk` | Обработать файл по чанкам. По умолчанию — по абзацам. |
| `/file_chunk paragraph=N` | Чанк из N абзацев. |
| `/file_chunk len=N` | Чанк длиной N символов. |
| `/file_chunk ... -y` | Авторежим: следующий чанк без подтверждения. |
| `@::путь::` | Подстановка содержимого текстового файла в сообщение. |

```
├── requirements.txt
├── ruff.toml
└── config.example.yaml
```
